## 完了ゲート

設計書「20. MVP受け入れ条件」10項目を、チェックリストとして全て満たす。

- [x] 新規ユーザーが名前を入力して開始できる
- [x] 6ステージが順番に解放される
- [x] 学習、クイズ、結果、報酬のループが成立する
- [x] 代表的な決まり手6種類、番付、本場所、基本ルールを学べる
- [x] 初回報酬が重複付与されない
- [x] セーブ後に再読み込みして再開できる
- [x] 横綱は最終試験合格時のみ取得できる
- [x] 未解放URLへの直接アクセスで進行を飛ばせない
- [x] 320px幅、タッチ、キーボードで主要機能を利用できる
- [ ] GitHub Pagesのリポジトリ配下URLでリンクと画像が壊れない

| 横綱の条件 | `e2e/progression.spec.ts` と `src/lib/ranks.test.ts` |
| 未解放URLの直リンク | `e2e/stage1.spec.ts` |
