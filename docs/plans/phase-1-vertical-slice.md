## 完了ゲート

本プロジェクト最大のチェックポイント。
GitHub PagesのURLで、以下が一度も詰まらず通ること。

- [ ] 名前を入力して開始できる
- [ ] マップからSTAGE 1へ入れる
- [ ] 学習を最後まで読み切れる
- [ ] 取組で正解・不正解の双方を体験できる
- [ ] EXPが入り、必要なら番付が上がる
- [ ] **ブラウザを再読み込みしても続きから再開できる**
- [ ] 同じステージを再プレイしてもEXPが二重に入らない
- [ ] E2E 1本目（新規開始→STAGE 1クリア）が自動実行される

## 注意点

このゲートを曖昧に通すと、以降の全ステージに同じ欠陥が複製される。
特に「初回報酬フラグ」と「リザルトの二重実行防止」は、ここで実機確認する。

E2E 1本目を完了条件に含めているのは、Phase 2の汎用化リファクタで壊れたことを即座に検知するため。
