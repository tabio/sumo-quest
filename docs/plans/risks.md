# リスク台帳

**このファイルは追記専用。**
既存の行を書き換えず、新しいリスクは表の末尾に足す。
IDは振り直さない。

`.gitattributes` で `merge=union` を指定しているため、複数人が同時に追記しても両方の行が残る。
その代わり重複行は自動検知されないので、追記前に既存の内容を確認すること。
