# ADR-0011: 決まり手八十二手の事実データを協会サイトから取得して持つ

状態: 採用
日付: 2026-11-15

## 背景

決まり手図鑑を作るにあたり、決まり手の全件を収録したデータが必要になった。

現在の `src/data/techniques.ts` は、学習で扱う代表的な6手のみを持つ（PRD「7. 学習ステージ」STAGE 3）。
決まり手は日本相撲協会が八十二手と定めており、これに勝負結果としての非技5つが加わる。

協会サイトの決まり手ページ（https://www.sumo.or.jp/Kimarite/show/ ）は、
プログラムからの取得を別ページへ転送して受け付けない。
一方、同ページが読み込む公開スクリプト2本に、技の一覧が表として含まれている。

- `/js/sekitorikun/CommonKimariteNew.js`：名称・読み・分類番号
- `/js/kimarite.js`：協会の技コードから上の表への対応

同ページの決まり手ランキングは、ページ本体のHTMLにあり、上記のスクリプトには含まれない。

協会サイトの解説文は協会の著作物である。
本作はGitHub Pagesで一般に公開する。

## 決定

**決まり手の事実データだけを協会の公開スクリプトから取得し、生成したデータファイルとしてリポジトリに置く。**

- 取得と生成は `scripts/scrape-kimarite.mjs`（`npm run scrape:kimarite`）が行う
- 解析と検査の規則は `src/lib/kimariteSource.ts` を正とする
- 生成物は `src/data/kimarite.ts`、分類は手書きの `src/data/kimariteCategories.ts` に置く
- 型は `src/types/game.ts` に `Kimarite`・`KimariteCategory`・`KimariteCategoryId` を追加する

収録するのは次の事実のみとする。

| 項目 | 内容 |
|---|---|
| `id` | 読みのヘボン式ローマ字。`Technique.id` と同じ規則 |
| `name`・`reading` | 名称と読み |
| `categoryId` | 基本技・投げ手・掛け手・反り手・捻り手・特殊技・非技 |
| `order` | 協会の掲載順 |
| `kyokaiCode` | 協会サイトが技を識別する番号 |

**解説文は取り込まない。**
図鑑の説明が必要になった場合は、本作で独自に書き起こす。
出典として、図鑑から協会のページへリンクする（`kimariteSource`）。

**ランキングは今回は収録しない。**
取得元のページが自動取得を受け付けないためである。
後から取り込む場合は、`kyokaiCode` を突き合わせのキーに使える。

取得元の読みには誤りが2件あった（小手投げ・ちょん掛け）。
生成データを手で直さず、`READING_CORRECTIONS` に正しい読みを足して再生成する。

## 理由

名称・読み・分類は事実であり、著作物に当たらない。
解説文まで取り込むと、許諾なく協会の文章を再配布することになる。

ページ本体ではなく公開スクリプトから読むのは、ページが自動取得を拒んでいるためである。
拒否を回避する手段（ブラウザを装う等）は取らない。

取得したスクリプトは評価せず、正規表現で決まった書式だけを読む。
管理外のコードを実行しないためである。
書式が変わって読めなくなった場合は、欠けたデータを出さずに止める。

実行時に取得しないのは、本作が静的サイトであり、サーバー処理を持たないためである（設計書の技術方針）。
取得は開発時に一度行い、結果をリポジトリに固定する。

読みは名称の送り仮名と照合して検査する。
取得元の2件の誤りはこの照合で見つかった。

## 影響

- `src/types/game.ts` に型が3つ増える
- `src/data/` に決まり手と分類のデータが加わる。既存の `techniques.ts` は変えない
- `techniques.ts` の6手が同じID・名称・読みで `kimarite.ts` に収録されていることをテストで保証する
- 図鑑の画面はまだこのデータを使っていない。画面への反映は別途決める

## 検討した代替案

### 協会のページ本体をスクレイピングする

ランキングまで一度に取れる。
しかしページは自動取得を別ページへ転送して拒んでおり、回避は取得元の意図に反する。

### 解説文も取り込む

図鑑の情報量が増える。
しかし協会の著作物を公開サイトで再配布することになり、許諾が要る。

### 手で全件を書き起こす

取得元に依存しない。
しかし87件の転記は誤記を生みやすく、出典との突き合わせもできなくなる。
