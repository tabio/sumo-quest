# PRD：SUMO QUEST（スモウクエスト）

## 1. プロダクト概要

### コンセプト

相撲を知らない人が、レトロRPGの世界を冒険しながら「大相撲を観戦し、基本的に何が起きているか分かる状態」まで楽しく学べるWebコンテンツ。

ユーザーは見習い力士としてゲームを始め、ルール、番付、決まり手、本場所などを学ぶ。クイズ形式の「取組」に勝つと経験値を獲得し、番付を上げながら横綱を目指す。

本格的なRPGではなく、レトロRPGのUIと演出を活用したインタラクティブな学習サイトとして設計する。

## 2. 背景と課題

相撲は日本を代表する文化・スポーツだが、番付、決まり手、仕切り、立ち合い、勝ち越し、金星、本場所、行司、呼出など、初心者には分かりにくい用語や仕組みが多い。

一般的な入門サイトは文章中心になりやすく、学習の負担を感じやすい。そこで、冒険、昇進、技の習得、対戦、図鑑、マップ探索というRPGの構造を学習体験に取り入れ、遊びながら知識を身につけられるようにする。

## 3. プロダクトゴール

### 最重要ゴール

一通りプレイした初心者が、大相撲中継を見て基本的な勝敗、用語、番付、場所の進行を理解できる状態になること。

知識の暗記ではなく、実際の観戦に結びつく理解を重視する。

## 4. ターゲットユーザー

- 相撲についてほとんど知らない小学生から大人
- 相撲を見たことはあるがルールを知らない人
- 家族の影響で興味を持った人
- 初めて国技館や本場所を観戦する人
- 子どもに相撲を教えたい人
- 日本文化として相撲を知りたい人

相撲に関する前提知識は不要とする。

## 5. UXコンセプト

ユーザーは「相撲を勉強する」のではなく、「相撲の世界を冒険する」感覚で学ぶ。

基本ループ：

```text
マップを進む
  ↓
NPCと会話して学ぶ
  ↓
知識・技を獲得する
  ↓
取組（クイズ）に挑む
  ↓
EXPを獲得する
  ↓
番付が上がる
  ↓
次のエリアが解放される
```

## 6. 世界観

「和風 × 相撲 × レトロRPG」を基調とした架空の相撲の国。主人公は相撲を何も知らない見習い力士で、各地を巡りながら横綱を目指す。

```text
よこづなの城
      │
 国技館の町
      │
ばんづけ神社
      │
  わざ道場
      │
    土俵
      │
  すもう部屋
      │
    START
```

## 7. 学習ステージ

### STAGE 1：すもう部屋

テーマは「相撲ってなに？」。

- 相撲、力士、土俵、まわしとは何か
- 土俵外に出る、または足裏以外が地面につくと負け
- 1回の試合を「取組」と呼ぶ

クリア後、見習い力士として認定する。

### STAGE 2：土俵

テーマは「相撲の基本ルール」。

- 勝敗条件
- 立ち合い
- 仕切り
- 待った
- 物言い

ここで最初の取組クイズを実施する。

### STAGE 3：わざ道場

テーマは「決まり手」。MVPでは次の6種類を扱う。

- 押し出し
- 寄り切り
- 叩き込み
- 突き落とし
- 上手投げ
- 下手投げ

学習した決まり手は「技」として技図鑑に登録する。

### STAGE 4：ばんづけ神社

テーマは「番付」。

```text
横綱 → 大関 → 関脇 → 小結 → 前頭
                         （幕内）
             十両 → 幕下 → 三段目 → 序二段 → 序ノ口
```

横綱、大関、幕内、関取、勝ち越し、負け越し、昇進、降格を学ぶ。

### STAGE 5：国技館の町

テーマは「大相撲を観戦しよう」。

- 本場所と1場所15日間の仕組み
- 年6場所（初、春、夏、名古屋、秋、九州）
- 土俵入り、横綱土俵入り、弓取式
- 大相撲の1日の流れ

### STAGE 6：横綱の城

全範囲から出題する最終試験。規定数の問題に正解すると横綱に勝利し、プレイヤーも横綱へ昇進する。

## 8. RPGシステム

### 経験値

目安として、学習完了で10 EXP、クイズ正解で10 EXP、ステージクリアで50 EXPを付与する。最終値はプレイ時間と昇進テンポを見て調整する。

### 番付をレベルとして利用

```text
序ノ口 → 序二段 → 三段目 → 幕下 → 十両
→ 前頭 → 小結 → 関脇 → 大関 → 横綱
```

通常のレベル表記を使わず、進行そのものによって番付の順序を覚えられるようにする。

### 取組（クイズ）

クイズをRPGの戦闘として演出する。正解時はプレイヤーの技と勝利演出を、不正解時は相手の技と短い解説を表示する。間違いに強いペナルティは設けず、理解と再挑戦を促す。

## 9. コレクション

### 技図鑑

学習済みの決まり手を表示し、未学習項目は「？？？」とする。名称、短い説明、難易度を掲載する。

### 相撲用語辞典

ゲーム内で出会った用語を自動登録する。用語は五十音順に表示し、未発見のものは原則として表示しない。

## 10. NPC

- 親方：基本ルール
- 行司：取組と判定
- 呼出：土俵と運営
- 先輩力士：稽古と決まり手
- 相撲博士：歴史と豆知識

長文記事ではなく、短い会話の連続で知識を伝える。

## 11. セーブ

MVPではログイン、サーバー、データベースを使わず、ブラウザのlocalStorageへ次を保存する。

- プレイヤー名
- 番付と経験値
- クリア済みステージ
- 習得済み決まり手
- 発見済み用語
- クイズ履歴

## 12. 主要画面

- タイトル（はじめから、つづきから、図鑑、辞典）
- 名前入力
- ワールドマップ
- ステージ学習
- 取組クイズ
- リザルト／昇進
- 技図鑑
- 相撲用語辞典
- プレイヤーステータス
- 横綱到達エンディング

## 13. デザイン方針

1990年代の16bit JRPGを想起させる、オリジナルのピクセルアート表現とする。特定作品のUI、キャラクター、音楽、素材は模倣しない。

- ピクセルフォントとドット絵
- タイルマップ風の世界地図
- RPG風メッセージウィンドウ
- 限定した色数
- 控えめなドットアニメーション
- スマートフォン優先の操作領域

サウンドはMVP必須外とし、将来、決定音、勝利音、太鼓、拍子木、歓声などをON/OFF付きで追加する。

## 14. MVPスコープ

### 含めるもの

- タイトルとプレイヤー名入力
- RPG風マップ
- 6ステージの学習コンテンツ
- 取組クイズ
- EXPと番付昇進
- 代表的な決まり手6種類
- 技図鑑と用語辞典
- localStorageセーブ
- 横綱最終試験
- スマートフォン対応
- GitHub Pagesでの静的配信

### 含めないもの

- ユーザー登録、サーバー、データベース
- マルチプレイ、ランキング、課金
- 自由移動を伴う本格RPG
- 複雑な戦闘システム
- リアルタイムの大相撲情報

## 15. 技術方針

- Next.js App Router
- TypeScript
- Static Export
- GitHub Pages
- 学習・クイズデータはTypeScriptまたはJSON
- プレイヤーデータはlocalStorage
- サーバーサイド処理は使用しない

## 16. 成功指標

- ゲーム開始からSTAGE 1までの完了率
- ステージ間の進行率
- 横綱到達率
- クイズ正答率と再挑戦後の改善
- 技図鑑・用語辞典の閲覧率
- 再訪率
- 終了後の基本相撲クイズ正答率

特に横綱到達率と、プレイ後に実際の相撲を理解できるかを重視する。

## 17. Version 1.0 完成条件

1. 初回ユーザーが説明なしで開始できる。
2. 6エリアを順番に進める。
3. 基本ルール、代表的な決まり手、番付、本場所を学べる。
4. クイズ形式の取組が成立する。
5. EXPにより番付が上がる。
6. ブラウザを閉じても進行状況が保存される。
7. 最終試験クリアで横綱になる。
8. スマートフォンで問題なくプレイできる。
9. GitHub Pagesだけで動作する。

## 18. プロダクト原則

1. RPGを作ること自体を目的にしない。ゲームは学びたくなる仕掛けである。
2. 1回の説明を短くし、「学ぶ→操作する→クイズ→演出」を小刻みに繰り返す。
3. 不正解を罰せず、理由が分かる説明と再挑戦を用意する。
4. ゲーム内で完結させず、「本物の大相撲を見てみたい」という気持ちにつなげる。
